## 🌟 Overview

**AlphaPulse India Pro** is a desktop-class quantitative trading, post-tax portfolio intelligence, and conversational AI execution terminal engineered for Indian stock market investors and traders (NSE / BSE).

Engineered with a **Full 3D Immersive Three.js WebGL Spatial Canvas**, a **Bento Multi-Window Bloomberg Quant Desk Mode**, an **Interactive Spotlight Omnibox (`⌘K`)**, a **Spacebar QuickLook HUD**, a **15M ORB Intraday MIS 5x Terminal**, a **10,000-Path Monte Carlo Post-Tax Simulator**, and an **Institutional Conversational AI Copilot**, AlphaPulse provides end-to-end mathematical rigor from live market discovery to post-tax bank account realization.

## ⚡ Quick Start & Installation

### Prerequisites
- **Python 3.12+**
- **Node.js 18+ & npm**

### 1. Clone the Repository
```bash
git clone https://github.com/deadheaven07/AlphaPulse.git
cd AlphaPulse
```

### 2. Environment Configuration
Create a `.env` file in the root directory:
```env
PORT=8000
HOST=0.0.0.0
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Automated One-Command Launch
```bash
chmod +x start.sh
./start.sh
```
This concurrently starts the FastAPI backend on `http://localhost:8000` and the React Vite frontend on `http://localhost:5173`.
